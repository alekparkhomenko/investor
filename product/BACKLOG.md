# Backlog: Investor

## P0 (Must Have)

### P0-001: Получение котировок MOEX
**Описание:** Приложение получает real-time данные с MOEX ISS API
**Критерии приёмки:**
- [ ] Запрос к MOEX ISS API каждые N секунд (настраивается)
- [ ] Парсинг цен LAST для акций TQBR (Т+)
- [ ] Поддержка символов: SBER, GAZP, MOEX (настраивается)
- [ ] Обработка ошибок сети и timeout

**SP:** 3

### P0-002: Graceful Shutdown
**Описание:** Корректное завершение работы при SIGINT/SIGTERM
**Критерии приёмки:**
- [ ] Закрытие соединений
- [ ] Финализация логов
- [ ] Очистка PID файла

**SP:** 1

### P0-003: Configuration via .env
**Описание:** Настройка через environment variables
**Критерии приёмки:**
- [ ] SYMBOLS=SBER,GAZP,MOEX
- [ ] POLL_INTERVAL=4s
- [ ] LOG_LEVEL=info

**SP:** 2

## P1 (Should Have)

### P1-001: Telegram Alerts
**Описание:** Отправка уведомлений в Telegram при изменении цены
**Критерии приёмки:**
- [ ] BOT_TOKEN и CHAT_ID в конфиге

**Критерии приёмки:**

- [ ] Уведомление только при изменении направления
